# java-calculator-precourse

## 문자열 덧셈 계산기

---

### 기능

**문자열 입력**
**빈 문자열에 대한 유효성 검사**

    - 빈 문자열인 경우, 0으로 처리
    - 그렇지 않을 경우, 다음 과정으로 진행

**커스텀 구분자가 존재하는 지에 대한 유효성 검사**

    - "//" 로 시작하는 커스텀 구분자 시작 기호가 앞에 존재할 경우, 문자열 끝가지 "\n" 이라는 형태가 존재하는 지 검사
        - 있을 경우, 구분자를 변수에 저장 -> 구분자 flag 값 1로 업데이트
        - 그렇지 않을 경우, IllegalArgumentException
    - 커스텀 구분자가 존재하지 않을 경우, 다음 과정으로 진행

**문자열에 대한 유효성 검사**

    - A) 숫자로 시작하지 않는 경우 IllegalArgumentException
    - B) 숫자로 시작하는 경우
        - 다음 입력값이 숫자면, 이전 숫자의 자릿수를 올리고, B를 계속해서 루프
        - 다음 입력값이 , 또는 ; 이면, 최종 변수값으로 확정 후 문자열 인덱스 + 2로 넘어가서 B 루프
        - 다음 입력값이 다른 문자라면
            - 커스텀 flag 가 0이라면 IllegalArgumentException
            - 1이라면
                - 커스텀 문자열과 동일하다면, 최종 변수값으로 확정 후, 커스텀 문자열 자릿수만큼 넘어가서 B 루프
                - 커스텀 문자열과 동일하지 않다면, IllegalArgumentException
        - 다음 입력값이 비었다면(문자열 끝이라면) 결과 출력 후 종료
